등급 변화초급 → 중급 → 해결사 → 해결사상승 2회 후 유지. 등급이 오른 주차를 짚을 수 있다

실행량 추세80 → 140 → 264 → 4,946마지막 주가 18.7배. 아래 주의 항목 참조

힌트 추세— → — → 4.5 → 40.86두 주가 결측이라 추세선을 그릴 수 없다
활동 밀도 추세0.43 → 0.57 → 0.57 → 1.00주 3일에서 7일로. 학습 리듬이 잡히는 과정
축약 주차가 추이를 끊는다. W33·W34는 metrics_snapshot이 7필드라 힌트·재시도·정체·에러 유형이 없다. 이 넷은 4주 중 2주만 선이 그려진다. 결측을 0으로 이으면 "힌트를 안 쓰다가 갑자기 40회"라는 없는 이야기가 만들어진다.
