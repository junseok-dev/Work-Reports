4. 누적으로 만들 수 있는 것

/sync/students는 주차가 없는 대신 주간 리포트에 없는 재료를 준다. 출결·과제·퀴즈에 더해 학습 시간이 여기 있다.

curl -X GET "$B/sync/students?limit=200" -H "X-DE-API-KEY: $DE_API_KEY"
항목원천 필드황수빈 실측계산과 의미
학습 시간atmux.total_duration_hours28.7시간실습 서버에 접속해 있던 총 시간. 주간 리포트에 없는 값
일 평균 학습 시간atmux.weekly_daily_avg_hours4.1시간서버가 이미 계산해 준다. 우리가 나눌 필요가 없다
실습 서버 부하atmux.avg_cpu_util29.5%평균 CPU 사용률. 학습 강도의 보조 신호

출결 구성attendance{5종}36/11/2/3/2출석·지각·조퇴·결석·공결 일수
출석률present ÷ 합계36 ÷ 54 = 66.7%지각·조퇴를 출석으로 치면 90.7%. 어느 정의를 쓸지 정해야 한다

퀴즈 응시율attempted ÷ total6 ÷ 7 = 85.7%주간 리포트에는 퀴즈 필드가 아예 없다

학습 시간은 지금까지 놓치고 있던 재료다. "일일 평균 학습 시간"을 화면에 넣으려면 별도 수집이 필요하다고 봤지만, atmux.weekly_daily_avg_hours가 이미 계산된 값으로 온다. 다만 누적이라 주차별로는 나눌 수 없다.
