1. 검증 개요

GOV-AI DataLake 명세서(REPORT-API-CALL.md v1.3)가 정의한 5개 API를 2026-09-03에 직접 호출해 실제 응답 필드를 확인했다. 주간 진단 리포트 화면을 구성할 때 어떤 값을 쓸 수 있고 어떤 값이 없는지를 호출 근거와 함께 정리한다.

검증 대상: https://datalake.isitsoft.kr/api/v1 · API v1.0.0 · 인증 헤더 X-DE-API-KEY. 검증 수강생은 명세서 예시와 동일한 100030029410(정승, 29기 A반)이다.

호출 환경

이 문서의 모든 명령은 아래 환경변수를 전제한다. 키는 저장소에 두지 않는다.

export DE_API_KEY="<명세서 1.1의 X-DE-API-KEY>"
export B="https://datalake.isitsoft.kr/api/v1"
export U="100030029410"
export PYTHONIOENCODING=utf-8
Windows 주의: Git Bash·PowerShell 모두 curl.exe에 명령행 인자를 넘길 때 한글을 시스템 코드페이지(CP949)로 변환한다. 한글이 든 요청 본문을 -d로 인라인 전달하면 서버가 UTF-8로 디코딩하지 못해 400 There was an error parsing the body가 난다. 본문은 파일로 저장해 --data-binary @file로 보내야 한다. macOS·Linux에서는 명세서 예시가 그대로 동작한다.

응답을 읽을 때

curl -sS "$B/reports/weekly/$U?format=json" -H "X-DE-API-KEY: $DE_API_KEY"   | python -m json.tool --no-ensure-ascii

PYTHONIOENCODING=utf-8과 --no-ensure-ascii가 둘 다 있어야 한글이 보인다. 앞이 없으면 콘솔 코드페이지에서 깨지고, 뒤가 없으면 정승 형태로 이스케이프된다.
