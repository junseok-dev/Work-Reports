5. 학생별 진단·주차 관리 흐름

  1. 수강생 선택: 역할이 조회 가능한 기수 수강생 목록을 받고 studentUuid를 선택한다.
  2. 주차 표시: 선택 학생의 완료된 주차 목록을 받고 최신 주차부터 왼쪽 사이드 탭으로 나열한다.
  3. 상세 확인: 선택 학생·주차의 진단 본문과 제안 초안, 저장된 강사 피드백을 한 번에 받는다.
  4. 강사 수정·저장: 저장본이 없으면 suggestedFeedbackDraft를 textarea value로 사용한다. 수정 후 PUT으로 저장하며 상태는 DRAFT다.
  5. 운영 확인: 운영은 같은 학생 선택·주차 사이드 탭·진단 본문과 강사 저장본을 읽기 전용으로 본다.
  6. 운영 일괄 발송: 현재 선택 주차를 POST한다. BE가 해당 기수·주차의 모든 DRAFT 강사 피드백을 조회해 수강생별 알림을 만들고 SENT로 변경한다.

반드시 구분할 화면 상태

  • 기수 수강생 없음 / 수강생 목록 호출 실패 / URL의 학생이 허용 목록에 없음.
  • 선택 학생의 주차 없음 / 주차 목록 호출 실패 / URL의 주차가 해당 학생에게 없음.
  • 상세 호출 실패 / 일부 지표 null / 제안 초안 없음 / 강사 저장본 없음.
  • 강사 저장 중·실패·완료와 운영 발송 중·부분 성공·전체 성공을 구분한다.
  • 운영 일괄 발송은 해당 주차 draftCount가 1 이상일 때만 활성화한다.

기존 수강생 본인 API /student/course/diagnosis/my-reports[/{week}]에는 다른 학생 식별자를 붙이지 않는다. 지도자 화면은 전용 경로와 권한 검사를 사용한다.
