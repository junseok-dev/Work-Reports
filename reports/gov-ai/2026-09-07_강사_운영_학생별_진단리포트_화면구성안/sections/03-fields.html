3. 화면 필드와 요청 매핑

지도자 FE 조회 순서는 기수 수강생 목록 → 선택 학생의 주차 목록 → 학생·주차 상세다. 원천 GOV-AI 필드는 BE가 camelCase 화면 계약으로 변환하고, 피드백 단계는 LMS가 별도 관리한다.

화면BE 응답 필드원천/저장 필드처리 원칙
수강생 드롭다운studentUuid, name, reportCountLMS 기수 명단 + 진단리포트 매핑선택 value는 studentUuid. 이름은 표시 전용
주차 사이드 탭week, baseDate, endDate, feedbackStatus, readyCount, sentCount선택 학생의 완료 리포트 + 기수·주차별 발송 집계최신 완료 주차를 기본 선택. 상태는 NONE / TEMP_SAVED / READY_TO_SEND / SENT
판정·근거level, confidence, gradeRationale, weakPatternsgrade, confidence, grade_rationale, weak_patterns수강생은 confidence를 숨기고, 강사·운영은 내부 검토용으로 표시
교직원 확인 정보riskFlags, recommendationsForInstructor, analyzedAt, dataFreshnessGOV-AI 분석 결과·시각강사·운영 화면에만 위험 신호·지도 제안·분석 시각을 별도 표시
결측 정보missingMetricsGOV-AI 원천 미제공 항목수강생은 해당 값을 —와 쉬운 안내로 표시하고, 강사·운영은 원천 키 목록도 확인
활동 지표metrics.activeDays, totalRuns, totalErrors, errorPerRun, hintRequestsCount, hintPerActiveDay, avgRetryGapMin, maxRetryGapMin, topErrorTypesmetrics의 snake_case 필드0은 실제 0, null은 원천 미제공. missingMetrics와 함께 항목별로 — 표시
AI 원문suggestedFeedbackDraftsuggested_feedback_draft편집 초기값의 마지막 대안. 별도 참고 블록에 표시하고 자동 발송하지 않음
역할 전용 임시저장본instructorFeedback.temporaryDraftLMS 역할별 작업본현재 역할에게만 보이며 저장 완료 전에는 운영 발송 대상이 아님
저장 완료본instructorFeedback.savedFeedback, hasUnsentChanges, managerNotifiedAtLMS 공유 저장본강사·운영이 수정 가능. 강사 저장 시 운영 알림, 미발송이면 발송 대기
발송본instructorFeedback.publishedFeedbackLMS 수강생 공개본운영 일괄 발송이 끝난 본문. 수강생 본인 상세에는 이 본문만 전달

편집 초기값 우선순위는 temporaryDraft → savedFeedback → suggestedFeedbackDraft다. readyCount와 sentCount는 선택 학생 개인 수가 아니라 해당 기수·주차 집계이며, 운영 일괄 발송 버튼과 결과 갱신에 사용한다.
