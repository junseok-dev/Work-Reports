3. 화면 필드와 요청 매핑

지도자 FE 조회 순서는 기수 수강생 목록 → 선택 학생의 주차 목록 → 학생·주차 상세다. 아래 지도자 계약은 현재 로컬 mock 기준이며, 실제 BE에는 아직 없다.

화면예정 응답 필드현재 출처처리 원칙
수강생 드롭다운studentUuid, name, reportCountFE staff mock선택 value는 studentUuid. 이름은 표시 전용
주차 사이드 탭week, baseDate, endDate, feedbackStatus, readyCount, sentCountFE staff mock최신 완료 주차를 기본 선택. 상태는 NONE / TEMP_SAVED / READY_TO_SEND / SENT
판정·근거level, confidence, gradeRationale, weakPatterns수강생 진단 원천을 mock에 재사용수강생은 확신도를 숨기고, 강사·운영은 내부 검토용으로 표시
교직원 확인 정보riskFlags, recommendationsForInstructor, analyzedAt, dataFreshness현재 FE 로컬 생성·시드강사·운영 화면에만 표시. 실제 정책·저장 주체는 BE 계약 시 확정 필요
결측 정보missingMetrics현재 수강생 BE에도 존재0과 결측을 구분. 수강생은 —와 안내, 강사·운영은 원천 키 목록도 확인
활동 지표metrics.activeDays, daysSinceLastActivity, totalRuns, totalErrors, errorPerRun, hintRequestsCount, hintPerActiveDay, avgRetryGapMin, maxRetryGapMin, topErrorTypes수강생 진단 원천을 mock에 재사용0은 실제 0, null은 원천 미제공. missingMetrics와 함께 항목별로 — 표시
AI 제안 초안suggestedFeedbackDraft현재 고정 샘플·템플릿실시간 AI 호출 결과가 아니다. 편집 초기값의 마지막 대안이며 자동 발송하지 않음
역할 전용 임시저장본instructorFeedback.temporaryDraftlocalStorage mock현재 역할에게만 보이며 저장 완료 전에는 운영 발송 대상이 아님
저장 완료본instructorFeedback.savedFeedback, hasUnsentChanges, managerNotifiedAtlocalStorage mock강사·운영이 공유. 강사 저장 시 운영 알림, 미발송이면 발송 대기
발송본instructorFeedback.publishedFeedbacklocalStorage mock운영 일괄 발송이 끝난 본문. 수강생 본인 상세에는 이 본문만 전달 예정

편집 초기값 우선순위는 temporaryDraft → savedFeedback → suggestedFeedbackDraft다. readyCount와 sentCount는 선택 학생 개인 수가 아니라 해당 기수·주차 집계이며, 운영 일괄 발송 버튼과 결과 갱신에 사용한다.
