4. 원천·mock·작업본·공개본의 분리

현재 실제 BE의 저장된 진단값, FE 로컬 샘플이 생성하는 교직원 확인 정보, 앞으로 LMS가 관리할 피드백 상태를 분리한다.

데이터현재 출처·책임화면 사용
주간 진단 본문GOV-AI history 적재 후 LMS-BE 조회수준·판정 근거·지표는 공통 사용. 수강생은 확신도를 숨김
위험 신호·지도 제안현재 FE 로컬 샘플 생성강사·운영 전용. 실 API의 정책·생성 주체는 아직 미확정
AI 제안 초안현재 FE 고정 샘플·템플릿실시간 AI 호출 결과가 아님. 교직원 참고·편집 초기값이며 자동 발송하지 않음
임시저장본현재 localStorage mock · 향후 LMS 역할별 작업본강사 작업본은 강사에게, 운영 작업본은 운영에게만 표시
저장 완료본현재 localStorage mock · 향후 LMS 공유 저장본강사·운영이 함께 확인·수정. 강사 저장 시 운영 알림과 발송 대기 상태 생성
발송본·알림현재 localStorage mock · 향후 LMS-BE운영 일괄 발송 결과를 수강생별 공개본과 개인 알림으로 반영

FE는 GOV-AI API를 직접 호출하지 않는다. API 키를 브라우저에 노출하지 않고, 같은 주차의 서로 다른 관측본을 섞지 않으며, BE가 적재·권한·식별자 매핑을 책임지는 구조가 필요하다.

AI 제안 초안과 임시저장본은 발송물이 아니다. 강사 또는 운영이 저장 완료한 최신 LMS 피드백만 발송 대기 대상이며, 운영의 일괄 발송을 거친 publishedFeedback만 수강생 리포트에 반영한다.
