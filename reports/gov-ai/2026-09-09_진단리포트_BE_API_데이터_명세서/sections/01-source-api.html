1. GOV-AI API 1~5 중 무엇을 쓰는가

번호GOV-AI 주소나오는 데이터진단리포트 사용
API 1GET /reports/weekly/{studentUuid}?format=json현재 주차 지표·등급·근거·위험 신호·지도 제안·피드백 초안참고 API 4와 중복. 현재 LMS-BE는 호출하지 않음
API 2GET /certificate/{studentUuid}역량 증명서·전체 단계 수·증명서 단위 승인 정보미사용 주차별 진단 화면용이 아님
API 3POST /analysis/diagnose/{studentUuid}새 등급·근거·위험 신호·지도 제안·피드백 초안미사용 온디맨드 재분석용이며 현재 조회·저장 흐름에서는 호출하지 않음
API 4GET /reports/history/{studentUuid}?limit=N학생의 주차별 진단 이력과 지표 스냅샷현재 사용 LMS-BE가 수집·저장하는 진단리포트 원천
API 5POST /feedback/approve최종 피드백 승인 요청과 log_id발송 시 선택 LMS 저장 상태를 대신할 수 없으며, 운영 발송 때 학생별 외부 승인 로그가 필요하면 호출
BE 구현 기준: 화면 조회값은 API 4에서 수집합니다. 피드백 임시저장·저장·발송 상태는 API 1~5가 아니라 LMS DB에 저장합니다. API 5는 최종 발송 시 외부 승인 로그가 필요할 때만 별도로 연결합니다.
