연동 현황과 BE 전달 경계

현재 실제 BE API는 3개입니다

경로현재 기능
GET /student/course/diagnosis/my-reports수강생 본인의 완료 주차 요약 목록
GET /student/course/diagnosis/my-reports/{week}선택 주차 상세와 직전 저장 주차 비교값
POST /admin/diagnosis/{studentUuid}/collectGOV-AI DataLake의 완료 주차 수집·적재

수집 API는 재분석 API가 아닙니다. 이미 저장된 주차는 unchanged로 건너뛰고 재분석하거나 덮어쓰지 않으므로 운영 재분석 버튼에 바로 연결할 수 없습니다.

수강생 본인 조회

  • 현재 BE 상세 필드는 주차·기간·등급·등급 근거·확신도·보완 패턴·지표 기준 시각·결측·지표·직전 주차입니다.
  • FE는 수강생 화면에서 confidence를 숨깁니다.
  • FE 계약에는 발송본용 instructorFeedback이 선택 필드로 정의되어 있지만 현재 BE 상세 DTO에는 없습니다.
  • 실 공개 흐름을 연결하려면 content, authorName, updatedAt, sentAt을 추가하고 발송본만 응답해야 합니다.

강사·운영 관리 — 모두 예정 계약입니다

학생 목록·학생별 주차 목록·상세 조회와 피드백 임시저장·저장, 운영 재분석·일괄 발송은 FE 요청 계약과 localStorage mock만 있고 BE에는 아직 없습니다.

역할조회변경수강생 공개
강사담당 기수 학생·주차·상세역할 전용 임시저장 · 저장 완료 시 운영 알림직접 공개하지 않음
운영운영 범위 학생·주차·상세임시저장 · 저장 · 재분석 예정 · 주차 일괄 발송일괄 발송으로 공개본 생성
수강생본인 완료 주차만없음발송본만 열람

교직원 상세에 추가되는 예정 필드

  • studentUuid, studentName: 선택 학생 식별 정보
  • riskFlags: 지도자 개입이 필요한 위험 신호
  • recommendationsForInstructor: 수강생에게 직접 공개하지 않는 지도 행동 제안
  • suggestedFeedbackDraft: 피드백 편집 초기 후보
  • analyzedAt: 진단 생성 시각. dataFreshness와 의미가 다름
  • instructorFeedback: 역할별 임시저장본, 공유 저장본, 발송본, 변경 상태, 운영 알림 시각

위 필드 중 riskFlags, recommendationsForInstructor, suggestedFeedbackDraft, analyzedAt, instructorFeedback은 현재 staff API가 없어 로컬 mock 값입니다.

피드백 상태

NONE → TEMP_SAVED → READY_TO_SEND → SENT
       역할별 초안       공유 저장본       수강생 발송본
  • 초기 편집 내용은 현재 역할 임시저장본 → 저장 완료본 → AI 제안 초안 순으로 채웁니다.
  • 강사와 운영의 임시저장본은 서로 보이지 않습니다.
  • 강사 저장 시 managerNotifiedAt이 생기고, 운영 저장 시 일괄 발송 대기가 됩니다.
  • 일괄 발송은 readyCount > 0일 때만 활성화되고, 응답 예정값은 requestedCount, sentCount, skippedStudentUuids입니다.

실제 결측 판정

  • daysSinceLastActivity == null → daysSinceLastActivity
  • hintRequestsCount 또는 hintPerActiveDay가 null → hintUsage
  • avgRetryGapMin 또는 maxRetryGapMin이 null → retryGap
  • topErrorTypes가 비어 있음 → topErrors

로컬 mock과 실서버 전환

  • 기본 로컬 모드에서는 진단 handler가 수강생·강사·운영 경로를 처리합니다.
  • VITE_REAL_DIAGNOSIS=true이면 handler를 등록하지 않고 실서버로 전달합니다.
  • 실서버 실패를 mock으로 대체하는 fallback은 없습니다. 미구현 지도자 API는 404가 날 가능성이 큽니다.
  • 로컬 mock 성공은 BE 기능 완료나 AI 연동 완료의 증거가 아닙니다.
