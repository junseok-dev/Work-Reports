GOV-AI 검증 인덱스

GOV-AI DataLake 연동 검증을 호출·파악에서 화면 렌더까지 다섯 단계로 나눠 정리했다. 알고 싶은 항목에서 해당 단계의 해당 장으로 바로 들어갈 수 있다.

작성일 2026-09-03보고서 5건API 실호출 검증

다섯 단계

GOV-AI DataLake 명세서(REPORT-API-CALL.md v1.3)의 5개 API를 2026-09-03에 직접 호출해 응답을 확인했다. 목표는 받은 데이터로 수강생 주간 진단 리포트를 채우는 것이고, 거기까지 가는 길을 다섯 단계로 나눠 기록했다. 명세서의 다섯 API만 근거로 쓴다 — 문서에 없는 엔드포인트는 계약 밖이라 언제 사라져도 이상하지 않으므로 제외했다. 앞 단계의 결론이 다음 단계의 입력이 된다.

1 호출·파악  →  2 추가 검토  →  3 확정  →  4 mock 구성  →  5 화면 렌더
단계보고서다루는 것이런 질문의 답이 있다
1단계
호출·파악		API 응답 필드 정리5개 API를 어떤 명령으로 불렀고 무엇이 왔는가. 필드 전체와 값의 형태, 출결·과제·퀴즈어떤 필드가 오나 · 그 값이 어떤 모양인가 · 출결이 왜 100.0인가
2단계
추가 검토		API 응답 기반 분석 가능성받은 값으로 어떤 통계를 계산하고 어떤 분석을 서술할 수 있는가더 뽑을 지표가 있나 · 추이로 뭘 말하나 · 뭘 못 만드나
3단계
확정		추가 항목 확정후보 20종을 판정하고, 재료가 없는 5종을 가른다무엇을 넣기로 했나 · 왜 뺐나 · 처음 원했던 다섯 가지는 어떻게 됐나
4단계
mock 구성		mock 데이터 구성안실응답만으로 mock을 어떻게 나누고 무엇을 넣는가몇 개 파일인가 · 필드가 각각 뭔가 · 결측을 어떻게 두나 · 뭘 손봐야 하나
5단계
화면 렌더		주간 진단 리포트 항목별 데이터화면 항목마다 어떤 값이 들어가 어떤 숫자·문장이 되는가지표 8칸이 뭔가 · 서술은 어떻게 만들어지나 · 안 나오는 값은 왜 필요한가
