3. 응답 필드 사전

2장의 다섯 호출이 돌려준 필드를 전부 편다. 각 필드가 무엇인지, 어떤 값이 왔는지, 진단 리포트가 쓰는지를 함께 적는다. 표의 출처는 아래 호출을 가리킨다.

출처호출무엇을 부른 것인가
API 1GET /reports/weekly/$U?format=json주간 AI 학습 맞춤 진단 리포트
API 2GET /certificate/$ULMS 연동용 역량 증명서
API 3POST /analysis/diagnose/$U온디맨드 수준 진단
API 4GET /reports/history/$U?limit=5주차별 리포트 이력
API 5POST /feedback/approve강사 피드백 승인
쓰임 열은 수강생 주간 진단 리포트와의 관계를 셋으로 나눈다. ● 화면에 값이 나온다 · ◑ 화면에 나오지는 않지만 필요하다 — 호출 식별자이거나, 지금은 상수·파생으로 대체 중이다 · · 지금은 쓰지 않는다. ◑가 붙은 이유는 표 아래 「화면이 읽지 않아도 필요한 값」에 적었다. 어느 필드가 화면의 어느 항목이 되는지는 항목별 데이터 보고서에서 다룬다.
