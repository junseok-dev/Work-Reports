4. 현재 구현 상태 — 실데이터 통합 연동

2026-08-07 로컬 코드 기준이다. AWS 실행 기반과 별도로 운영 DB 원천이 증명서 화면까지 연결되는 데이터·서비스 구현 상태를 정리한다.

FE 증명서 화면일부 구현

증명서 화면은 있으나 운영 실데이터가 아니라 mock·fixture 중심이다.

운영 DB 추출미구현

수료 트리거, 증명서 원천 조회와 수강생 단위 데이터 취합이 구현되지 않았다.

데이터 전처리미구현

Parquet 변환, 타입 통일, 검증·정규화와 데이터 없음 상태 생성이 구현되지 않았다.

S3 데이터 연동미구현

기수·수강생·버전별 저장, manifest와 FastAPI S3 Repository가 구현되지 않았다.

AI 분석 실데이터 연결골격만 구현

분석 API는 있으나 S3 정제 입력 조회, AI 허용 필터와 분석 결과 저장은 구현되지 않았다.

Spring BE 응답 조립미구현

분석 요청·완료 수신, S3 전체 취합, 검토·공개 정책과 요청 시 응답 조립이 필요하다.

FE 실데이터 전환미구현

Spring BE 실응답 연결, 데이터 없음 상태와 런타임 mock 제거가 남았다.

전체 E2E미검증

DB→S3→FastAPI→Spring BE→FE 흐름을 실제 수료자 기준으로 검증해야 한다.
