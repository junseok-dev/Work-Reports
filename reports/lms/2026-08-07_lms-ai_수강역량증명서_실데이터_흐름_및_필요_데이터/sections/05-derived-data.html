5. FastAPI가 만드는 파생데이터

파생데이터는 원천 수집 항목이 아니라 FastAPI가 정해진 산식으로 만드는 값이다. 계산 입력, 정책, 결과 필드, 사용처와 데이터 없음 처리를 함께 명세한다.

No.파생데이터계산 입력계산식·정책결과 필드·타입사용처·데이터 없음 처리
1출석률인정 출석 시간, 전체 인정 수업 시간recognized_minutes / required_minutes × 100. 소수점·상한 처리 기준은 계산 정책 버전에 고정attendance_rate: number종합요약 탭
전체 인정 시간이 없으면 NO_DATA
2평가 환산점수·성취도획득 점수, 만점, 평가 유형, 채점 상태채점 완료된 유효 결과만 100점 기준으로 환산하고 반영 대상의 평균 계산normalized_score: number
achievement_score: number		종합요약·기술검증·AI 분석 탭
유효 평가가 없으면 NO_DATA
3역할별 4축 점수동료·멘토·강사·운영의 기술기여, 소통협업, 문제해결, 책임감 1~5점역할별 평균 후 (평균-1)/4×100. 누락 역할을 0점으로 채우거나 임의 재가중하지 않음role_axis_scores: object종합요약·평가·추천 탭
일부 역할이 없으면 PARTIAL
46축 역량점수역할별 4축, 출석·학습 참여, 평가 성취도각 축을 0~100으로 정규화하고 버전별 산식으로 6축 값을 생성competency_axes: object종합요약 탭
필수 입력이 부족하면 해당 축 NO_DATA

grade: string		종합요약 탭
필수 축 부족 시 PARTIAL
6프로젝트 수행지표프로젝트 기간·역할·기술·성과·인증 상태, 프로젝트별 GitHub 커밋 활동전체·완료·인증 프로젝트 수와 주요 역할·활용 기술을 집계하고, 저장소별 본인 커밋 수를 전체 커밋 수로 나눠 커밋 기여율을 계산project_metrics: object

7문제해결 지표·AI 준비 상태인증 사례, 카테고리, 해결 소요일, 독립 해결, 지원 활용, 근거 존재 여부인증 사례만 대상으로 카테고리 분포·평균/중앙 소요일·근거 준비 상태 생성. 사례 수만으로 역량점수 생성 금지problem_solving_metrics: object
ai_readiness_status: enum		문제해결·AI 분석 탭

저장 기준은 기수 ID + 수강생 UUID + 입력 버전이다. 결과에는 calculation_policy_version과 generated_at을 함께 저장해 동일 입력의 재검증이 가능하게 한다.
