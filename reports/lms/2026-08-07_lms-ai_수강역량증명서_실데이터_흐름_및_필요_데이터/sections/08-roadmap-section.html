5. AWS를 포함한 남은 작업 순서

필드 계약 확정
증명서 데이터 필드와 운영 DB 원천, 필수·선택·공개·AI 허용 범위를 연결한다.
추출·전처리 구현
수료 트리거, DB 조회, Parquet 변환, 검증·정규화를 구현한다.
S3 정책 확정
파티셔닝, manifest, 파일 크기, 버전·재처리·보존 정책을 정한다.
FastAPI 실연결
S3 조회, 파생 계산, AI 허용 필터, 작업 상태와 결과 저장을 구현한다.
ECR 이미지 확정
헬스체크를 수정하고 현재 소스를 SHA 이미지로 빌드·push해 digest를 확인한다.
ECS 실행 기반 완성
task role, 서비스, private network, 보안그룹과 호출 주소를 구성한다.
배포·관측 검증
Actions 배포를 활성화하고 CloudWatch 로그·알람·롤링 배포·롤백을 시험한다.
Spring BE 연동 구현
FastAPI 호출과 결과 취합, 인증·권한·검토·공개 정책, 요청 시 응답 조립을 구현한다.
FE 전환·mock 제거
Spring BE 실응답을 조회하도록 연결하고 런타임 mock·fallback을 제거한다.
