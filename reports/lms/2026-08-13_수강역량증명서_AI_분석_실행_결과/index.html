2. AI 분석이 의도대로 나왔는가

자동검사는 코드가 계약·계산·근거 코드·개인정보를 반복 확인하는 검사다. 의도 적합성 검토는 생성 결과가 입력 근거와 현재 화면 기획에 맞는지 항목별로 판단하는 검토다. 미리 만든 AI 답안과 문장 일치율은 사용하지 않았다.

검증 가능한 15개 항목은 모두 통과했다. 전체 18개 중 팀 과업의 황수빈 귀속·완료 상태·프로젝트별 본인/동료 근거 3개는 현재 mock으로 판정하지 않았다.

해석 주의: 검증 가능 범위는 15 / 18 = 83.3%이며, 그 범위 안의 통과율은 15 / 15 = 100%다. 검증 불가 3건을 실패나 성공으로 계산하지 않았다. 따라서 다른 수강생이나 실데이터에 대한 정확도 100%를 의미하지 않는다.

3. 현재 구조로 계속 진행해도 되는가

황수빈 mock의 채움 정도를 운영 데이터 준비도로 환산하지 않는다. 원천 데이터 계약의 개인 귀속 가능성, 로컬 실행 검증 범위, 실데이터 확인 시점을 서로 분리했다.

고정 직무 목록 없이 현재 업무 근거와 맞닿는 직무·역할을 제안하고 적합도를 보수적으로 판단한다.

  • 직무명·역할명·적합도 점수
  • 직무별 직접 관련 이론 평가 선택
  • 프로젝트 반복 역할과 동료평가 4축 해석
  • 문제 구조화·적용·검증 패턴

LMS-AI 코드가 확정한 것

  • 프로젝트 3건과 수강생 UUID로 귀속 가능한 개인 과업

6. 직무 적합도 결과

고정된 7개 직무가 아니라 gpt-5.4-mini가 개인 수행·평가·자격·문제해결 근거에서 후보를 자유롭게 도출했다. 후보 하나에는 직무 하나만 표시한다.

84

데이터 엔지니어

수집·정규화 설계 · 신뢰도 HIGH

관심 직무 목록에 없지만 크롤러 구현, 데이터 정규화·검증과 PostgreSQL 사용 근거에서 자유롭게 도출됐다. SQL·데이터베이스 관련 평가 평균은 95.5점이다. 분산 처리·운영 배치 근거는 없다.

81

데이터 분석가

분석·대시보드 · 신뢰도 HIGH

상권 매출 EDA, 채용 데이터 분석과 대시보드 구현이 연결된다. Python·SQL 관련 평가 평균은 98점이다. 실험 설계·A/B 테스트·의사결정 개선 효과 근거는 제한적이다.

74

머신러닝 엔지니어

모델링·평가 · 신뢰도 HIGH

LightGBM 튜닝, 파생 변수와 데이터 누수 교정 근거가 있다. 자료구조·알고리즘 1개 평가만 직접 관련돼 이론 이해도는 PARTIAL이며, 배포·서빙·MLOps 근거는 없다.

점수의 의미 고정 가중 공식 없음 · LLM의 근거 기반 직무 적합 판단 점수는 현재 확인된 업무와 해당 직무의 맞닿음을 나타낸다. 관심 직무 미선택을 감점하지 않고, 관심 직무라는 이유만으로 가점하지 않는다. 이번 1순위 데이터 엔지니어는 관심 직무 밖에서 도출됐다. HIGH는 근거 종류가 다양하다는 뜻이며 취업 가능성을 보장하지 않는다.

  • 지원 포함은 머신러닝·협업 2건
검토 결과: 협업 사례를 독립 해결로 잘못 서술한 실제 LLM 오류를 검출했다. 최종 구현은 독립 1건·지원 2건을 원천에서 계산해 요약하며, 폐기된 문제해결 성장 분석은 결과와 품질 지표에서 제외한다. 협업 사례는 동적 카테고리에는 포함되지만 고정 3축에서는 미매핑이다.
황수빈 1명의 구조화된 입력과 실제 LLM 호출 결과를 기준으로 작성했으며, 전체 수강생 정확도를 의미하지 않는다.
