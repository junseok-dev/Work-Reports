8. 문제해결 분석 결과 상태

상황·해결 과정·결과가 모두 있는 인증 사례가 1건 이상이므로 입력 상태는 READY다. 사례 수를 역량 점수나 성장률로 바꾸지 않는다.

READY

데이터

  • merge 키 중복 원인 확인
  • 키 유일화와 validate 적용
  • 행 수 일치로 결과 검증
READY

머신러닝

  • 스케일러 데이터 누수 확인
  • Pipeline과 교차검증으로 이동
  • 부풀림을 제거한 성능 확인
READY

협업

  • rebase 충돌로 동료 커밋 손실
  • reflog와 백업 브랜치로 복구
  • 사전 백업 규칙으로 재발 방지
표시 기준원천 카테고리 그룹이 주 결과 · 데이터 처리/모델 개선/인프라 보조 축은 점수 없음협업 사례처럼 고정 보조 축에 매핑되지 않는 사례도 원천 카테고리에서는 빠지지 않는다. 폐기된 문제해결 성장 분석은 생성하지 않는다.
품질 판정: 계산 가능한 건수·기간·독립 여부와 근거 원문은 충분하다. 최종 요약 문장의 정확도는 다음 수용 결과에서 확인해야 한다.
