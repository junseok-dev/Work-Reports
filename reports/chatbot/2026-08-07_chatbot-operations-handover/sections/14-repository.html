개발 담당자용: 소스 코드 구조

기능을 수정하거나 장애 원인을 코드에서 확인할 때 참고하는 파일 안내입니다. 콘텐츠·상담 담당자는 이 절을 참고 범위로 두어도 됩니다.

backend/app/main.py — 앱 기동, 라우터, 정적 프론트 제공, 홈페이지 동기화 시작
├─ routers/chat.py — 채팅·SSE 요청의 전체 분기와 로그 저장
├─ routers/admin.py — 문서·FAQ·프롬프트·로그·데이터·설정 API
├─ routers/auth.py — Google OAuth 검증과 JWT 발급
├─ services/router_service.py — 하이브리드 라우팅
├─ services/rag_service.py — FAISS 검색·인덱스 생성·S3 동기화
├─ services/openai_service.py — 모델 호출·스트리밍·상담 응답 규칙
├─ services/website_course_service.py — 공식 홈페이지 수집·검증·스냅샷
├─ services/admin_service.py — 문서 처리·승인·재색인
├─ services/guardrail_service.py — 인젝션·개인정보·분노 정책
└─ db/models.py — 운영 DB 테이블 정의
frontend/src/ — React 사용자·관리자 UI
├─ pages/ChatPage.tsx — 사용자 채팅 화면
├─ pages/AdminPage.tsx — 관리자 대시보드
├─ hooks/useChat.ts — 대화 상태·스트리밍·기록
└─ services/api.ts — 백엔드 API 호출 모음
.github/workflows/deploy.yml — main 자동 배포
backend/tests/ — 상담·취업·포맷·홈페이지 파서 테스트
scripts/ — RAG 평가·진단 도구

스키마 적용: 백엔드 import 시 SQLAlchemy 테이블 생성과 migrate_database(engine)가 실행됩니다. 별도의 일반 마이그레이션 도구를 사용하는 구조는 아니므로, 스키마 변경 전에는 migration 코드와 운영 DB 백업을 함께 검토합니다.
