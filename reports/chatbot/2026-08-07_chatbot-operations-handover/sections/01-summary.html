한눈에 보기

이 시스템은 교육 과정 문의를 자동 응대하고, 필요한 경우 사람 상담으로 연결하는 문서·FAQ 기반 상담 서비스입니다.

React 18사용자 채팅·관리자 화면
FastAPIAPI·상담 오케스트레이션
Aurora RDS운영 데이터의 기준 저장소
FAISS + S3문서 검색 인덱스·영구 보관

핵심 운영 개요

이 챗봇은 회사 문서와 FAQ를 기반으로 교육 상담을 자동화하고, 개별 확인이 필요한 문의는 상담 담당자에게 연결하는 서비스입니다. 일상적인 콘텐츠·답변·권한 관리는 관리자 페이지에서 수행하며, 화면 구조·판단 로직·배포 방식 변경에만 개발 작업이 필요합니다.

담당 역할별 권장 열람 범위

콘텐츠·상담 담당자

현재 서비스 특징 → 챗봇이 참고하는 정보 → 관리자 운영 → 문제 대응을 우선 확인합니다. 코드·서버 항목은 참고 범위입니다.

서비스 운영 책임자

한눈에 보기 → 정기 운영·비용 → 계정·비밀정보 인계 → 최종 체크리스트를 우선 확인합니다.

개발·서버 담당자

전체 문서와 함께 아키텍처 → 배포·로컬 실행 → 레포 구조를 세부적으로 확인합니다.

핵심 기능 용어

EC2백엔드와 완성된 프론트엔드 파일이 실행되는 AWS 가상 서버입니다.
RDS대화 기록, 문서, FAQ, 설정과 감사 로그를 보관하는 운영 데이터베이스입니다.
S3업로드 문서와 검색 인덱스를 장기 보관하는 AWS 객체 스토리지입니다.
RAG회사 문서에서 관련 내용을 검색한 후, 그 근거를 사용해 답변을 생성하는 방식입니다.
FAISS질문과 의미가 가까운 문서 구간을 빠르게 찾기 위한 벡터 검색 인덱스입니다.
재색인변경된 문서·FAQ가 검색에 반영되도록 검색 인덱스를 다시 생성하는 작업입니다.
SSE생성 중인 답변을 브라우저에 실시간으로 전달하는 스트리밍 방식입니다.

서비스의 현재 역할

Q

사용자에게 제공하는 것

교육 과정 소개, 지원 대상, 커리큘럼, 일정·비용·장소, 입과 절차, 운영 규정, 취업 지원 범위를 한국어 상담 말투로 안내합니다. 답변은 실시간 스트리밍으로 표시되며 대화 맥락을 이어갑니다.

↗

사람에게 넘기는 것

수강 취소·환불·일정 변경, 사용자의 명시적 상담원 요청, 취업 결과 책임 공방처럼 개별 확인이 필요한 사안은 채널톡 상담 매니저 연결 버튼으로 전환합니다.

소스 보유 상태: 현재 원본 레포는 작성자가 보유합니다. 운영 연속성을 위해 최종 인계 시점의 코드 사본과 커밋 ID를 회사가 통제하는 저장소 또는 승인된 보관소에 남기고, 신규 담당자에게 읽기·쓰기 권한을 부여해야 합니다.
