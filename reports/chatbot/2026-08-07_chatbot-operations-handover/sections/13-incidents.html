문제가 발생했을 때

먼저 사용자 화면에서 문제 범위를 확인하고, 서버 작동 여부 → 오류 기록 → AWS·OpenAI 등 연결 서비스 → 최근 변경 사항 순서로 원인을 확인합니다.

우선 확인 순서

① 사용자 챗봇 접속 → ② 대표 질문 입력 → ③ 관리자 로그인 → ④ 최근 배포·콘텐츠 변경 확인 순서로 확인합니다. 화면 전체가 열리지 않거나 여러 기능이 동시에 실패하면 서버 담당자에게 전달하고, 특정 답변만 틀리면 문서·FAQ·홈페이지 정보부터 확인합니다.

증상우선 확인대응
사이트 전체 접속 불가도메인·프록시, EC2 상태, systemctl status chatbot, /health서비스 로그 확인 → 안전하면 재시작 → 최근 배포 실패 여부 확인
채팅이 fallback만 반환OpenAI 키·한도, 서버 오류 로그, 활성 모델명키/사용량/모델 가용성 확인, 필요 시 관리자에서 검증된 모델로 전환
검색 답변이 오래됨문서 승인 상태, FAISS 재구성, S3 권한, 홈페이지 sync 상태대표 문서 확인 → 관리자에서 재색인 → 필요 시 수동 홈페이지 동기화
관리자 로그인 실패Google Client ID, 승인 origin, ADMIN_EMAIL/admin_users, JWT_SECRETOAuth 설정과 회사 관리자 이메일을 대조한 뒤 재로그인
DB 연결 오류DATABASE_URL, RDS 상태, 보안 그룹, 자격증명네트워크·DB 상태 복구 후 서비스 재시작 및 쓰기 테스트
홈페이지 정보 미갱신app_settings.website_course_sync_status, 페이지 구조·교차 검증 실패backend/scripts/sync_website_courses.py 실행; 파서 테스트 후 코드 수정
상담 연결 버튼 없음CHANNEL_TALK_URL, 응답 source가 handoff인지 확인Secret과 배포 env 확인 후 취소·상담원 요청 시나리오 재검증
