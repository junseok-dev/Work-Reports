최종 인계 체크리스트

문서를 전달하는 것만으로 인계가 끝나지 않습니다. 신규 담당자가 직접 배포·수정·복구를 수행할 수 있어야 완료입니다.

소스·문서

  • 회사 관리 저장소 또는 승인된 보관소에 최종 코드 전달
  • 최종 기준 커밋 ID와 브랜치 기록
  • README와 이 인수인계 보고서 전달
  • 회사 소유자가 repository admin 권한 보유
  • 운영 URL·도메인·서버 경로 기록

계정·비밀값

  • GitHub Actions Secrets 접근 및 갱신 권한
  • AWS EC2·RDS·S3·IAM 접근
  • ENCRYPTION_KEY 복구 사본과 접근 절차
  • OpenAI 조직·결제·사용량 접근
  • Google OAuth·ChannelTalk·LangSmith 접근

운영 실습

  • 신규 담당자 계정으로 관리자 로그인
  • FAQ 1건 수정 후 답변 반영 확인
  • 테스트 문서 업로드·승인·재색인 실습
  • 대화 로그 조회·Excel 내보내기
  • 홈페이지 동기화 상태 확인·수동 실행

배포·복구 실습

  • 신규 담당자가 직접 main 배포 1회
  • GitHub Actions와 systemd 로그 확인

  • RDS 백업 정책과 S3 데이터 확인
