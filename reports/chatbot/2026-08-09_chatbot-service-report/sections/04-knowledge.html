지식과 관리자 운영

운영자는 대부분의 콘텐츠와 답변 기준을 코드 배포 없이 관리자 화면에서 변경할 수 있습니다.

승인 문서

과정 설명, 커리큘럼과 규정의 상세 근거입니다. 검토·승인된 버전만 검색에 사용합니다.

공식 홈페이지

모집 기수, 개강일, 시간, 장소와 비용을 마지막 성공 후 24시간 주기로 갱신합니다.

FAQ

반복 질문에 사용하는 기준 답변입니다. 유사 표현과 참고 문서를 함께 설정할 수 있습니다.

답변 규칙

말투, 답변 범위, 취소·상담 연결과 오류 안내 기준을 관리합니다.

자주 수행하는 운영 작업

업무별 안전한 작업 순서
업무작업 위치와 순서완료 확인
과정·규정 갱신문서 업로드 → 원문 대조 → 승인 → 필요 시 재색인새 문서 대표 질문과 기존 핵심 질문 확인
반복 답변 수정FAQ 중복 검색 → 질문·답변·유사 표현 수정원문·줄임말·자연어 변형 질문 확인
말투·처리 원칙 변경기존 프롬프트 기록 → 수정 → 정상·민감 질문 시험품질·속도·상담 연결 변화 확인
이용 현황 분석기간 지정 → 대화·처리 로그 조회 → Excel 내보내기기간·행 수·개인정보 포함 여부 확인
관리자 추가회사 Google 이메일 등록 → 신규 담당자 로그인주요 메뉴 접근 성공 후 기존 권한 정리

주의: DB 브라우저 직접 수정, 백업 없는 삭제, 계획 없는 복호화, 업무 집중 시간의 모델·프롬프트 변경은 피합니다. 일반 콘텐츠는 문서·FAQ·프롬프트 전용 메뉴를 먼저 사용합니다.
